# Lobbykin 0.9.4-rc1 — Plugin Hub pateikimo kandidatas

Tai šaltinio paketas, paruoštas iš v0.9.3. Pradėk nuo SUBMISSION_LT.md:
ten nurodyti likę build, gyvo bandymo ir viešo GitHub pateikimo žingsniai.
Angliškas README.md skirtas naudotojams ir RuneLite peržiūrai.

Vietiniam kūrimui reikia JDK17. Paleidimas: START_LOBBYKIN.bat arba
`gradlew.bat run`. Įdiegus per Plugin Hub po patvirtinimo, atskiro mūsų BAT ir
kūrimo JDK galutiniam naudotojui nebereikės.

Naršyklėje pasirink Connect with Lobbykin, patvirtink norimus leidimus.
Sekimui pasirink Track this session prieš įeidamas į raidą ir būdamas grupės
world. Mirtis nėra sėkmingas užbaigimas. Sekimas eksperimentinis; kelių dalyvių
užbaigimus sujungia serveris. Po RuneLite perkrovimo prisijungti reikia iš naujo.

Šio kandidato pilnas build ir gyvas OSRS bandymas dar nepatvirtinti.
Skaityk VALIDATION.md. Plugin Hub pateikimas ir patvirtinimas dar neatlikti.
