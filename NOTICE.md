# Sources and assets

- Gradle wrapper scripts, JAR and properties are from the official
  runelite/example-plugin template, retrieved 2026-10-28. Wrapper scripts retain
  their Apache License 2.0 headers. Gradle: https://www.apache.org/licenses/LICENSE-2.0
- Build and development launcher follow https://github.com/runelite/example-plugin.
- Sidebar registration follows RuneLite's ClientToolbar / NavigationButton APIs.
- icon.png is a small crop of the existing Lobbykin J imp reference asset. No new
  mascot was generated. It is a temporary raster icon, not a vector brand master.

  or published by Jagex or RuneLite. It has not been submitted to Plugin Hub.
