# Add Lobbykin

Lobbykin is an OSRS group coordination sidebar. It shows one current party,
Ready/Waiting roster states, collapsible scheduled groups and explicit world hop.
A Lobbykin account is required for connected group features.

Browser approval grants a scoped, revocable in-memory credential. Optional
permissions cover Ready changes, notifications and experimental raid reports.
Reports require an explicitly selected CoX/ToB/ToA session. Game-system messages
are interpreted locally; raw chat text is not uploaded. No combat automation,
Jagex credentials, native code, reflection or dynamic executable downloads are
used by the main plugin source. API destinations are under lobbykin.com.

PRIVACY.md and SECURITY.md document payloads, permissions and boundaries.
Cross-client completion matching is a backend heuristic, not official KC or
character ownership verification. The plugin uses build=standard and adds no
main-runtime dependency beyond RuneLite's transitive dependencies.
